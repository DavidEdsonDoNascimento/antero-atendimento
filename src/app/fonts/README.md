# Fontes locais

`Geist-latin.woff2` e `GeistMono-latin.woff2`: Geist e Geist Mono 1.401
(fontes variáveis, pesos 100–900, subconjunto latino), © 2024 The Geist
Project Authors, sob a SIL Open Font License 1.1 (`OFL.txt`).

São os mesmos arquivos distribuídos no pacote `next` 16.3.4 instalado
(`next/dist/next-devtools/server/font/`), copiados sem modificação para que
o build não dependa de baixar fontes do Google (`next/font/google`). O
subconjunto latino cobre o português (acentos, ç, travessão, reticências).
